        Connect your Govee

        Use your Govee as the room gauge, so the heater aims for the temperature where you are.

        Wi-Fi Works on iPhone
        1. Open the Govee Home app → Profile → ⚙️ Settings → Apply for API Key. Govee emails you a key, usually within minutes.
        2. Paste the key here and tap Find.

        Govee smart plug

        Plug the heater into a Govee Wi-Fi smart plug to cut its power completely, safely and from anywhere. Uses your free Govee API key (Govee Home → Profile → ⚙️ Settings → Apply for API Key).
